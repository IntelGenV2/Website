NL-02

NanoLab 2

Hardware

Two Arduino Nano R4s run the computer. One handles BASIC, and the other drives the VGA display. Programs are saved to EEPROM.

OVERVIEW

I kept NanoLab 1’s two-board setup and moved both jobs to ARM-based Nano R4s. I upgraded the display board for better graphics. The BASIC board has an 8 KB program buffer and supports both the NL1 and NL2 dialects.

WHAT IT CAN DO

  • Switch dialects: NL1 (integer 1.7) or NL2 (float BASIC)
  • NL2: floats, strings (A$), DIM, ELSE, WHILE, ON GOTO, STOP/CONT, logic ops, STR$/INSTR, BEEP/SOUND/PLAY, GET/INKEY$
  • NL1: classic integer mode with . / ? / ! aliases and TONE/TONEW
  • 8 KB program buffer (was ~1 KB on NanoLab 1) and deeper FOR/GOSUB stacks
  • Save, load and manage programs in EEPROM: ELOAD, ESAVE, ECHAIN, ELIST, EFORMAT
  • PS/2 keyboard on the R4, USB serial separate from the GPU link
  • Same VGA text terminal feel — clear, color cycle, block graphics

HIGHLIGHTS

  • BASIC processor and VGA graphics processor: Arduino Nano R4
  • Separate keyword tables per dialect — not a thin overlay
  • Boot password, memory bars, then the > prompt
  • Stack Two Arduino Nano R4s · dual-mode BASIC
  • Input PS/2 keyboard · USB upload
  • Display VGA text GPU board
  • Language NL1 integer · NL2 float/string
  • Storage EEPROM for saved programs
