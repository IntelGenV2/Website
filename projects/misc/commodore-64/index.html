Commodore 64 Projects

Here’s what I’ve been making for the C64 under Studio 256. There are a few Flash games I wanted to play on it, a puzzle game of my own, and a disk browser for my SD2IEC.

Loophole

It’s the same door, red button and pit, but the trick changes each time. I made forty rooms across four worlds. This one is from Seashore.

Bloxorz

I ported Bloxorz to the C64 from the Flash game of the same name. I got all 33 stages into one load, including the passcodes.

Download D64 · 1.0.0Source code

Awesome Tanks 2

There are 15 sectors from the Flash game. You uncover the map with the turret, shoot the bunkers and spend the coins on the tank. I put separate SID music in for the menu, combat and the campaign win.

Battle Tanks

This one is based on Niklas Frykholm’s Macintosh game. Pick an angle and power, fire, then adjust for the wind. The hills take damage, so the next shot can have a very different path.

Pac-Xon

Leave the blue ground, draw a line and get back before a ghost hits the trail. Claim 80% and you’re through.

DIR2

For the SD2IEC I worked on a disk browser with popup file tools. The first load is only 16 disk blocks. It reads the extra tools from the card the first time I need them and keeps them in memory.
