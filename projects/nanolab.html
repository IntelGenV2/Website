OVERVIEW

NanoLab is a customized BASIC mini computer that runs on two Arduino Nanos: one as CPU (interpreter + PS/2 keyboard) and one as GPU (VGA text renderer). Built by Laurence Bosch and treated as a flagship bench project.

It grows out of Rob Cai�s Arduino VGA Tiny Basic lineage and TinyBasic Plus, then strips, retunes, and extends the firmware for a specific hardware stack � including a boot sequence, password gate, memory screen, and command history.

HIGHLIGHTS

  • Dual-Nano CPU/GPU split with a serial protocol between boards
  • VGA text output and PS/2 keyboard input
  • Boot flow with memory status and tones
  • Expanded BASIC commands, aliases, and EEPROM workflow tools
  • Companion PC �NanoLab Sender� for pushing programs over serial
