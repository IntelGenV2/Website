IG-02

IntelGen Game Launcher

Software

Windows desktop launcher that pulls games from multiple stores into one translucent cover-art library.

OVERVIEW

IntelGen Game Launcher is a Tauri + React app for Windows. It discovers installed games across stores, shows them as a cover-art grid, and launches from one place — with search, filters, favorites, and playtime tracking.

WHAT IT CAN DO

  • Auto-discovers games from Steam, Epic, GOG, Battle.net, Ubisoft Connect, and Xbox / Game Pass (best-effort)
  • Add manual .exe titles when a store does not see them
  • Click cover art to launch; search, store filters, and favorites to keep the shelf usable
  • Tracks playtime and last played (imports Steam playtime when available)
  • Fetches covers from Steam, Epic, Wikipedia, and optional SteamGridDB
  • Live FPS overlay while a game runs (Intel PresentMon)
  • Glass / acrylic UI on Windows where supported

HIGHLIGHTS

  • One library across stores instead of five launchers
  • Missing games stay in the shelf with history intact
  • Local data under %APPDATA%\IntelLauncher\
  • Stack Tauri · React · TypeScript · Rust
  • Platform Windows
  • Stores Steam · Epic · GOG · Battle.net · Ubisoft · Xbox
  • Extras Cover art · playtime · FPS capture
