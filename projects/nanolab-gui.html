NL-03

NanoLab GUI

Hardware

ESP32 + FabGL VGA OS with a Win98-style desktop, explorer, terminal, and SD-card apps.

OVERVIEW

NanoLab GUI pushes the hardware line beyond a BASIC prompt into a full VGA desktop. Running on ESP32 with FabGL, it presents a Win98-inspired shell — login, explorer, terminal, and apps loaded from SD.

Where NanoLab focuses on the interpreter machine, this build is about the OS surface: windows, scripts, and the feeling of a small personal computer.

HIGHLIGHTS

  • ESP32 + FabGL VGA graphics stack
  • Win98-style UI (login, explorer, terminal)
  • SD card apps / NanoScript samples
  • Companion to the NanoLab BASIC hardware line
  • Stack ESP32 · FabGL · VGA
  • Storage SD card apps
  • UI Desktop / explorer / terminal
  • Era vibe Late-90s workstation
